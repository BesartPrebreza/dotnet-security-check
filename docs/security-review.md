# .NET Application Security Review

A paid, fixed-price engagement for one .NET application. The initial review focuses on classic ASP.NET applications hosted on IIS.

## What we can review

- The effective deployment configuration, including release transforms and applicable IIS or server defaults.
- Authentication and authorization configuration, including a sample of access rules for selected endpoints.
- Cookie settings, production error handling, and how deployment credentials are supplied.
- Selected NuGet dependencies and how the team checks for known advisories before release.

## What you receive

- A report with prioritized findings, affected components, supporting evidence, and practical remediation steps.
- A walkthrough of the findings and the checks that could be completed.
- One follow-up review of the agreed fixes.

## How to start

1. [Request a quote](https://github.com/BesartPrebreza/dotnet-security-check/issues/new?template=security-review-request.md) with your .NET version, hosting type, and review priorities.
2. Arrange a private channel to agree on access, pricing, timing, and the work for the application in scope. The team can walk through relevant settings in its own environment or share sanitized material through an agreed channel.
3. Approve the written scope and price before the review begins.

GitHub issues are public. Keep credentials, production configurations, internal URLs, and details of suspected vulnerabilities out of the request.
